Who did what

Bhatkal Time Luxe began as a HubZero client project: a watch-commerce website for a Bhatkal-based retailer, aimed at customers across India. I built it end to end through HubZero: the architecture, the frontend and full-stack implementation, the database and the infrastructure.

I designed the current storefront iteration, which is what the captures here show. The original design was created by one of my HubZero co-founders.

It was HubZero's first paid client project, and the first time I carried paid software from architecture through to production infrastructure for another business.

What was built

  • A Next.js App Router storefront, deployed on Vercel.
  • A separate Node.js API on a self-hosted Ubuntu server, backed by MongoDB.
  • An image pipeline through Cloudinary, with imgix in front for delivery.
  • Server-rendered pages with JSON-LD and a sitemap, so the catalogue is crawlable.

A currency experiment, after the fact

After the partnership began, I independently experimented with configurable currency presentation: the site can show prices in INR, KWD and other currencies from one selector.

KWD was used in that experiment. It was not a client requirement, and it is not evidence of a Kuwait or GCC market; the project's focus was India-wide.

Status and limits

  • The client did not continue the partnership. The website remains live as a showcase of my work, not an active storefront.
  • Client work: the code is not presented as a personal open-source project.
  • The live site is not linked from the portfolio, and no repository is linked.
