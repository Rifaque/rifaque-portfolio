Personal AI operating layer · case study

Nexus

A local-first, voice-first layer for one owner on one Windows machine. Deterministic recognition handles what it can without a model, a reasoning step is reached only when it declines, and every effect passes through one governed tool runtime.

The question

How can a personal AI stay useful without capability quietly becoming authority?

Most assistants become more useful by being allowed to do more. Nexus keeps those apart: it can hold a great deal of context about its owner and their work, while what it may actually change on the machine stays narrow, explicit and auditable.

There is no published interface. The drawing above is an illustration, and the monitor behind it carries only a label.

From words to effects

A request passes through layers that each decide one thing. Only the last one can change anything.

  • Command Fabric: deterministic, model-less recognition. "Set a timer for ten minutes" becomes a typed intent with typed slots, or is marked ambiguous, unsupported or a matter for the assistant. It cannot execute anything.
  • Response engine: deterministic wording for structured outcomes, with no model call.
  • Cortex: reached only when the deterministic layers decline. One bounded decision: answer, pick one governed capability from a closed set, ask, or delegate.
  • ToolRuntime: the only place an effect happens, behind a capability gate and a policy in which one deny beats any number of allows.

Approval that cannot drift

A consequential call needs explicit owner confirmation, and that approval is bound to a hash of the computed effect. The executor computes the effect itself; the model's description of it is never trusted. If the effect changes after approval, the approval is void.

Mutations are checkpointed in a shadow Git repository, and every call is recorded in an append-only, hash-chained ledger, denials and failures included.

Decisions and trade-offs

  • The defaults refuse. The standard policy stack is read-only, so every call at or above "mutate" is denied before confirmation is reached; mutating stacks are explicit opt-in configurations.
  • Dangerous capabilities stay absent. Host control registers no tool at all unless configured, and there is no shell, PowerShell or run-command tool.
  • Deterministic first. A model is used only where the deterministic layers cannot answer, which keeps common requests fast and predictable.
  • Voice without listening. Push-to-talk with no wake word and no background listening; speech-to-text runs locally on faster-whisper.

Status and limits

  • Private alpha: Windows only, single owner, unreleased, with no public demo or source.
  • The newest tag predates the desktop shell and voice. Those exist on working branches and have not been tagged or released.
  • Spoken acceptance of the voice endpoint on the owner's machine is paused.
