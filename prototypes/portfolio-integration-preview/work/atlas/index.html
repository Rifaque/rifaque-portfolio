Atlas

A Rust and Tauri 2 desktop app that indexes one codebase or document set and answers with inspectable evidence. A question without enough evidence in the workspace can be declined instead of answered from general model knowledge.

One loop, on purpose

Can an assistant answer from your workspace, and say so when it can't?

Earlier builds reached for more surfaces. For 1.0 the product was narrowed to a single loop: open a workspace, index it, ask or find, inspect the evidence, follow up.

Agents, arbitrary shell execution, personas, graph surfaces, web search and vision attachments are not part of 1.0.

Retrieval

Workspace files are chunked and embedded locally through Ollama. A question gathers semantic candidates and BM25 candidates, then:

  • reciprocal-rank fusion merges the two lists
  • candidates are classified for relevance and de-duplicated
  • a bounded evidence set goes to the model, or the question is declined

Indexing is incremental, and a damaged generated index can be detected and rebuilt without touching the source files.

Evidence you can inspect

Each answer shows the material supplied to or considered for it, with files and line ranges. That is the evidence considered, not sentence-level attribution, and the app says so.

Ask and Find follow different rules. Ask is conservative and can decline. Find can return bounded literal matches from the workspace when Ask would not answer.

An explicit cloud boundary

With local Ollama, indexing, embeddings, generation and evidence stay on the machine. OpenRouter is optional, enabled per request; a request that has not authorised it is blocked.

When it is enabled, Atlas assembles the complete bounded payload first and Secret Shield scans it for known secret formats, such as AWS keys, GitHub tokens and API keys. A match blocks the request. The OpenRouter key is held by the Rust side in the operating system's credential store.

Decisions and trade-offs

  • Fewer surfaces. One loop done properly rather than many half-finished ones; removed areas are not described as current.
  • Declining is a feature. Ask would rather say it lacks evidence than answer from general model knowledge.
  • Workspace authorization in the backend. Requested paths are canonicalised and confined to the workspace root in Rust.
  • A safety net, not a guarantee. Secret Shield matches known patterns; it protects the cloud path without promising more.

Status and limits

  • Windows x64 only. The installer is unsigned, so SmartScreen shows an Unknown Publisher warning; the release publishes a SHA-256 checksum.
  • The updater is disabled. Linux is configured but unverified, and macOS is unsupported.
  • PDF and generic-file chunking is basic, relevance calibration is heuristic and context budgeting is approximate.
