Layers by RSX

A customisable Android widget platform built around one portable widget definition, validated, themed and sized by a shared runtime. A browser editor, Layers Studio, is planned; it is not built.

One definition, one runtime

Every widget, first-party or imported, is a portable definition that goes through the same steps: a bounded parse, schema checks, resolution against theme, defaults and per-instance overrides, sizing from the widget's real dimensions, and rendering with RemoteViews.

Seven widget families are merged: Clock, Battery, Music, Calendar/Date, Countdown, Shortcuts and Device/System. Others exist on branches only.

Real sizes, previewed

Widgets size from their actual dimensions, with global and per-instance overrides in an explicit order. The editor previews compact, wide and large sizes side by side and adapts to large windows.

This capture is from an Android emulator with a large-window display override. It is not a physical tablet; physical tablets have not been verified.

On the home screen

The same runtime draws the widgets on the launcher. Imported packages use a bounded, validated .layers format; it is internal and provisional, not a public standard.

Widgets never run arbitrary code or intents: Shortcuts and Device/System use allowlisted host actions and typed capabilities.

What exists, and what is planned

The Android runtime, editor, themes and .layers import and export are implemented. Layers Studio is specified as a browser editor that opens the same .layers packages, with visual editing, live previews at several sizes and local use without an account.

No Studio source exists yet, so it has no screen to show anywhere on this page.

Status and limits

  • No public release; V1 is not released.
  • The .layers package format is internal and provisional.
  • Physical tablets, other launchers and spoken TalkBack have not been verified. Captures are from the emulator.
