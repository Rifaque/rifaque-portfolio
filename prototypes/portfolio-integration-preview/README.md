# Portfolio integration preview: Projection shell + Concept D Projects

One complete portfolio page for review: the Projection prototype's page (the three-wall RSX shadow hero and every other section), with Concept D, Project Space, in place of Projection's "The work" section. A reviewable prototype, not a production migration. Built 26 Oct 2026.

Nothing outside this directory was changed. `prototypes/projection/` and `prototypes/projects-redesign/` are read only (checked by checksum before and after), and `src/`, `public/` and the rest of the repository are untouched.

## How to view

From the repository root:

```
python -m http.server 8765 --bind 127.0.0.1
```

Open <http://127.0.0.1:8765/prototypes/portfolio-integration-preview/>. Bind to `127.0.0.1` only: the server exposes the whole repository, including the private notes file. A server is needed (ES modules).

Case studies: `work/<slug>/`, for example <http://127.0.0.1:8765/prototypes/portfolio-integration-preview/work/bhatkal-time-luxe/>.

Review switches, as in the two source prototypes: `?theme=dark|light`, `?motion=reduce`, `?webgl=off`, `?nointro`, `?clean` (hides Projection's Prototype panel), `?heroview=r|s|x`, `?sound=test`, `?project=<slug>` and `&open=1` (Project Space selection and detail view).

## What changed from the sources, and why

Only what the integration needed:

- `index.html`: Projection's page with the "The work" section replaced by Concept D's Projects markup; Concept D's detail `<dialog>` and two stylesheets added.
- `js/app.js`: Projection's home script without the work-bench code. The links that opened a project on the bench (Nexus and Atlas in How I work, the Bill of materials) now select it in Project Space; for QueryCraft and BlueTap, which are not in Project Space, they lead to the case study. "Open it on the bench" now reads "Open it in Projects".
- `js/study.js` (QueryCraft and BlueTap pages): the breadcrumb and page links lead to Projects and to the other Also built case study, since the six featured projects now have Concept D case studies.
- `js/projects/shared/shell.js`: Concept D's concept header, theme and sound controls are not used. Projection's header, theme switch and sound are the page's own; Project Space's two cues play through Projection's sound (which, as in Projection, is off until the Sound switch turns it on).
- `js/projects/space/space.js`: no concept header; buttons use Projection's primary style; a close cue; `selectProject()` for the links above.
- `js/projects/space/case-studies/cs.js`: Projection's shell instead of the concept header; "Back to Projects" leads to `?project=<slug>#work` on this page.
- `js/projects/shared/content.js`, `js/projects/space/data.js`: paths only, and the unused reference to the 2025 BTL collage removed (Concept D always replaced it with the INR captures).
- `css/projects.css`: Concept D's section styles (from `space.css`), plus the few atoms from its shared `base.css` that Projection's stylesheet does not have. Concept D's tokens were already a copy of Projection's, so palette, type and spacing are Projection's throughout.
- `work/<six slugs>/`: generated by `tools/make-pages.mjs` from Concept D's case-study pages (read only).

Copied unchanged: `css/tokens.css`, `css/app.css`, `css/stage3d.css`, `css/cs.css`, `fonts/`, `vendor/three.min.js`, `js/hero.js`, `js/triplet.js`, `js/sound.js`, `js/shell.js`, `js/content.js`, `js/illustrations.js`, `js/projects/space/scenes.js`, `js/projects/space/stage3d.js`, `js/projects/space/case-studies/diagrams.js`, `js/projects/shared/illustrations.js`, `work/querycraft/`, `work/bluetap/` (one nav link pointed at `#work`).

## MVP pass (26 Oct 2026)

Fixes, all inside this directory:

- **Brand.** The header shows the approved RSX Develops wordmark (dark export in the dark theme, light export in the light theme) instead of the cube glyph and text. Favicons are the approved `favicon.ico` and the dark tile PNGs. All are copied into `brand/` from `public/rsx-develops-brand-assets/` (unchanged). The Google Play header is not used.
- **Theme and sound controls.** The theme switch names the theme it switches to ("Light" in dark, "Dark" in light), with a matching icon and accessible name. Sound is an icon-only button named "Enable sound" or "Mute sound" from the actual audio state. It is still off until the visitor turns it on. Header links, Also built, archive links and the detail view's actions use the existing `press` and `open` cues.
- **Hero loading.** While WebGL starts, the room stays empty instead of showing the finished poster, which the entrance would then take apart. The poster now appears only as the deliberate no-WebGL fallback. The hero's footprint is fixed by CSS, so nothing shifts.
- **Hero dragging.** The text-and-controls layer (`.hero-grid`, `.hero-object`) sat above the canvas, so the solid could only be grabbed from the outer margins. Its empty parts now pass the pointer through, while the copy and the R/S/X controls keep theirs. Phones keep `touch-action: pan-y`, so vertical swipes still scroll.
- **Detail view.** Status and summary lead, with one primary "Read the case study" action. Then come My part, Facts, Highlights and Limits, with the project's own links as secondary. The media column is labelled "Evidence", and the close button is a 44px target.
- **Also built.** QueryCraft and BlueTap both open their case studies. Each page now opens with a restrained 3D object in the Project Space style (`js/projects/space/also-scenes.js`): an abstract, labelled illustration of the workflow, not a screenshot.
- **Experience and education.** Title, kind and organisation share one line, and rows are tighter. On phones, dates and the bar share a row. Height went from 986 to 742 px at 1440 px wide and from 1563 to 1173 px at 390 px, with all eight entries and every fact kept.
- **Bill of materials.** In the light theme, dimmed chips use 0.62 opacity instead of 0.32, which clears the contrast threshold.
- **Archive builds** (under Also built, in Projects). Each entry was checked against its repository's code on 26 Oct 2026, not only its README:
  - HubZero website (github.com/HubZeroHQ/hubzero, hubzero.in): Next.js 15 and TypeScript with a first-party Studio CMS over MongoDB and NextAuth. The knowledge base records "Shipped the studio's site"; GitHub lists Rifaque as the only committer (384 commits). Described as HubZero's site.
  - ZeroLink: Next.js client, Express/TypeScript server on `ws`, Firebase ID tokens checked per socket, data in MongoDB (Mongoose). The README's claim that messages are stored in Firebase is not what the code does. All commits are from 30 Jul 2025.
  - Blood Report Disease Diagnosis: Flask, a scikit-learn random forest on a 298-row CSV of nine blood-count values, a cause lookup, and SQLite accounts and history. Described as academic, not a clinical tool.
  - Hospital Management System: Python/Tkinter (sv-ttk, Pillow) over MySQL (`mysql-connector`); a committed `hospital.db` is unused. Billing, prescriptions and search from the README are not implemented, so they are not claimed.
  - DevPilot stays out. College Management App, Carbon Footprint Tracker and the 2023 electronics project were not added.
